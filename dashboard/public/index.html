From city API to chart, every night.

Five automated stages run on a schedule in the cloud. Nobody has to keep a laptop open.

  1. Extract

    Pulls every record from the city's open data API, retrying if the network drops.

  2. Validate

    Checks columns, timestamps and required fields. Bad data stops the run before it reaches the database.

  3. Transform

    Removes duplicate and invalid IDs, then splits each timestamp into year, month, day and hour.

  4. Load

    Upserts into a Supabase PostgreSQL database, so running it twice never creates duplicates.

  5. Serve

    This site reads the database through a small API and redraws every chart for the year you pick.
